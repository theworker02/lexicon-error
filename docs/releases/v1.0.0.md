# LexiconError v1.0.0

## Stable desktop release

LexiconError v1.0.0 is the first stable release of the offline diagnostic encyclopedia. It combines a 16,474-record SQLite/FTS5 catalog with an information-rich native desktop workspace for understanding compiler diagnostics, runtime exceptions, infrastructure failures, and GPU runtime faults.

## Highlights

- 16,474 locally searchable records across 44 ecosystems, with no account, server, telemetry, or required network connection.
- Four interactive inspector workspaces for root-cause analytics, trigger-versus-fix code, situational context and cross-language relationships, and failure-state provenance.
- Experience-likelihood visualization that explicitly distinguishes curated frequency from measured incident probability.
- Catalog-derived frequency and failure-domain graphs with clickable, ecosystem-scoped filters.
- Resolvable related-diagnostic navigation across languages, including conceptual equivalents.
- Verification state, toolchain identity, canonical IDs, version boundaries, catalog cohort counts, source quality, and dataset provenance.
- SQLite FTS5 search, pasted-error detection with sensitive-line redaction, hierarchical filters, command palette, context matrix, and coverage dashboard.
- Validated JSON and Markdown/YAML contribution imports plus portable SQLite backup and structured export utilities.
- CUDA, ROCm/HIP, Vulkan, and OpenCL coverage alongside core language, framework, infrastructure, database, and configuration diagnostics.

## Desktop experience

The v1.0.0 interface replaces the earlier thin inspector with a denser three-pane diagnostic workspace. Every visible analytic control performs a real local query or filter action. Frequency charts use catalog counts, related-diagnostic cards open actual indexed records, and the provenance view reports the verification and dataset metadata stored with the selected diagnostic.

## Release assets

- `LexiconError_1.0.0_x64-setup.exe` - recommended Windows x64 installer.
- `LexiconError_1.0.0_x64_en-US.msi` - MSI package for managed Windows deployment.
- `lexicon-error-2026.08-reviewed.db` - portable SQLite/FTS5 catalog backup.

The desktop installers bundle the reviewed catalog and remain fully functional offline after installation.

## Important notes

- The included native binaries target Windows x64. Build the same source on macOS or Linux to create platform-native bundles.
- Catalog volume does not imply that every generated registry record is editorially complete. Use the visible verification state and official source link when accuracy matters.
- Frequency labels are curated ordinal classifications, not live telemetry or guaranteed real-world probabilities.
- Code examples are documentation and are never executed by LexiconError.
- Local contributions are stored in the user application-data database and are not added automatically to the bundled portable catalog.

## Data and support

The public derived-metadata dataset preserves provenance and source notices. Its aggregate license is `other` because upstream terms differ; review the repository source manifest and dataset notice before republishing the complete corpus.
