# LexiconError v0.1.0

## The offline diagnostic atlas

LexiconError v0.1.0 is the first packaged desktop release of the local-first catalog for compiler diagnostics, runtime exceptions, configuration failures, and GPU runtime faults.

## Highlights

- 16,474 searchable diagnostic records across 44 languages and 45 tools.
- Native dark-mode desktop workspace with domain tree, dense catalog, root-cause/diff/context inspector, matrix, coverage dashboard, and Ctrl+K/Cmd+K command palette.
- SQLite FTS5 search with no server, account, telemetry, or required network connection.
- CUDA, ROCm/HIP, Vulkan, and OpenCL error coverage alongside core language and tooling diagnostics.
- Local contributions from JSON or Markdown/YAML frontmatter, with schema validation and portable database backup/export.
- Provenance-aware record metadata, source notices, quality tiers, and explicit Needs Review status for generated registry entries.
- GitHub Pages discovery site, plus prepared Hugging Face Dataset and static Space packages.

## Release assets

- LexiconError_0.1.0_x64-setup.exe: recommended Windows x64 installer.
- LexiconError_0.1.0_x64_en-US.msi: MSI installer for managed deployment.
- lexicon-error-2026.08-reviewed.db: portable SQLite/FTS5 catalog backup.

The desktop installers bundle the reviewed catalog and function fully offline after installation.

## Important notes

- This initial native release is Windows x64. Build the same source on macOS or Linux for their platform-native bundles.
- The catalog has broad coverage but does not claim that every registry import has a reviewed explanation or repair. Use the verification status and official source link when accuracy matters.
- Examples are documentation only and are never executed by LexiconError.
- The included portable database can contain only the bundled catalog. Locally imported contributions are stored in the user application-data database and are not part of this release.

## Data and support

The public derived-metadata dataset retains source provenance and notices. It is labeled license: other because upstream terms differ. See the repository source manifest and dataset NOTICE before republishing the corpus.
